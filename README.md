# T-Lab 2026 RecSys — Решения тестовых заданий (1 и 2)

Репозиторий содержит полное исследование, воспроизводимый код и выполненные в Kaggle ноутбуки по обоим заданиям отбора **T-Lab 2026 (RecSys)** на промышленном датасете **[Yambda-50M](https://huggingface.co/datasets/yandex/yambda)** (Яндекс Музыка, 10 000 пользователей, 47.79M событий).

---

## Навигация по репозиторию

### [Задание 1. Автоматизация построения признаков в рекомендательных системах](task1/README.md)
- **Отчёт:** [`task1/README.md`](task1/README.md)
- **Код и ноутбуки:**
  - [`task1/task1_pipeline.py`](task1/task1_pipeline.py) / [`task1/task1_feature_automation.ipynb`](task1/task1_feature_automation.ipynb) — ручной бейзлайн `H` (49 признаков), усиленный экспертный бейзлайн `H-strong` (54 признака с состоянием сессии), грамматика признаков `A-all` (538 признаков), жадный автоматический отбор блоков `A-select` (82 признака за 4.5 мин), разрешение парадокса `ROC-AUC` vs `NDCG@10` через `Snapshot-NDCG@10` и `LightGBM LambdaRank`, а также нейросеть `MultiHorizonNet` с обучаемыми горизонтами.
  - [`task1/task1_B.py`](task1/task1_B.py) / [`task1/task1_B_decay.ipynb`](task1/task1_B_decay.ipynb) — потоковый подход `B`: инкрементальные экспоненциально затухающие счётчики ($O(1)$ памяти на сущность), нейросеть `B-net` с обучаемыми мягкими окнами и дистилляция выученных окон в LightGBM.
- **Выполненные Kaggle-ноутбуки с логами (все 10 000 пользователей):**
  - [`t-res1.ipynb`](t-res1.ipynb) (и [`t-res1111.ipynb`](t-res1111.ipynb)) — полный прогон `H`, `H-strong`, `A-all`, `A-select`, `H + A-select`, `Snapshot-NDCG@10`, `LambdaRank`, `Calibrated Ranker` и `MultiHorizonNet`;
  - [`t-res1-2.ipynb`](t-res1-2.ipynb) — прогон потоковых экспоненциальных ядер `B-grid`, `B-net` и `B-net features → LightGBM`.

```bash
pip install polars pyarrow lightgbm huggingface_hub scikit-learn numba torch transformers matplotlib

# Задание 1 (подходы H, H-strong, A, Snapshot-NDCG, LambdaRank и MultiHorizonNet)
python task1/task1_pipeline.py

# Задание 1 (подход B: потоковые затухающие счётчики и обучаемые окна B-net)
python task1/task1_B.py

# Задание 2 (GPT-2 + две Reward Models + аналитический оптимум + REINFORCE + multistep RL + OPE)
python task2/task2_rl.py
```
